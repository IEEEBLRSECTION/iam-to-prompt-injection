Secrets and logging

A debug log becomes another data leak

INFO prompt="Customer: asha@example.com
Internal API token: DEMO-ONLY-NOT-A-SECRET
Please summarize this support request."

Vote: where did the secret spread before the model answered?

The prompt now contains the secret. A log may retain it even after the chat window closes.

Keep credentials at the tool boundary

Secrets Manager supplies credentials to the backend at runtime. The model receives only the tool result it needs.

Control the evidence you retain

CloudWatch and Bedrock invocation logs need deliberate content, retention and access settings. A log can become a second copy of sensitive input.
