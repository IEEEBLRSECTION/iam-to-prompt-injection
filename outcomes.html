How AI applications fail

Four outcomes that need different evidence

01

Response deviation

The answer moved away from the task.

02

Data disclosure

Protected information was returned.

03

Attempted action

The model proposed a tool call.

04

Executed action

The backend actually ran it.

A strange answer is not an account compromise. A failed attack is still a result.

33:00–35:00. One click per step. For each attempt ask what actually happened: did the answer change, was protected information returned, was an action proposed, did the backend execute it? Those observations need different evidence. Do not claim a model is vulnerable because a payload was submitted, and do not relabel a blocked attempt as a compromise. Also name unsafe output handling and excessive agency: generated text can become application behaviour, and more agency raises the impact of a wrong tool decision.
