A successful login does not authorize every document or operation.

Subramanya · 05–17 min

Teach: shared responsibility. AWS secures the cloud; the application team owns authorization inside the application. Human identity versus workload identity: a person signs in through Cognito and gets tokens; a Lambda function runs under an IAM execution role and receives temporary credentials from STS. Prefer temporary access over embedded static keys. Authorization lives in IAM policies, resource policies such as S3 bucket policies, and application-level decisions; Verified Permissions is the managed option for fine-grained application authorization. IAM Access Analyzer helps find unused access and access shared outside the account. Exit check: participants distinguish authentication from authorization.
