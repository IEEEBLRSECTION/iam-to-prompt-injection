Both · reference

Preferred delivery is a speaker-hosted browser lab: a small backend in Lambda behind API Gateway, deployed and verified before the event. Hosting charges are separate from Guardrails charges. Store counters in a shared backend store such as DynamoDB rather than in each Lambda instance’s memory. Participants may alter only designated lab settings or choose between prepared scenarios; their ability to submit prompts stays separate from any ability to change the protected backend. After the event: close the endpoint or expire sessions, remove only event-created resources, delete S3 objects and versions before removing an event-only bucket, remove temporary roles and credentials, and check billing again once usage records settle.
